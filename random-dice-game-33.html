My Account

Where your save lives

Your profile auto-saves after every match, pull, and deck change. It's stored both in this app's own storage and in your browser's local storage, so it should survive updates to this game. Still, browsers can clear local storage — use the tools below to keep an outside copy.

Export

Download a save file, or copy a short code you can paste back in later (or on another device). The code is lightly obfuscated with a tamper-check — not real encryption, just enough to discourage casual editing.

Import

Paste a save code, or upload a .json save file.

Redeem a Gift Code

Enter a gift code to add that die to your collection as a new Class 1 copy.

Reference Codes

A code exists for every die currently in the game. Each is lightly obfuscated with a tamper-check, same as save codes — not real security, just enough to discourage casual editing. Each code can only be redeemed once per profile.

Reset Profile

Erases gold, collected dice, and your deck on this device. This can't be undone unless you've exported a save first.
